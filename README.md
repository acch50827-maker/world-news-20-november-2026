A one-page newspaper front page summing up the world's news of Friday 20 November 2026: the world court ruling that Myanmar committed genocide against the Rohingya, the first three-way Trump–Xi–Putin summit in Shenzhen, the massive overnight strike on Kyiv, the Houthi missile that damaged Riyadh's tallest tower, a fifth straight day of falling markets, and the day's ticker. A deterministic Node 22 program (standard library only) draws the 1024x1024 PNG from scratch — a 5x7 bitmap font, hand-drawn illustrations, and a PNG encoder written by hand.

## Run it

```sh
OUTPUT_DIR=./output node main.ts
```
